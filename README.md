# ArogyaJal - Water Quality & Health Surveillance System

**जल गुणवत्ता निगरानी प्रणाली**

## Overview

ArogyaJal is an integrated water quality monitoring and health surveillance system designed for North East India. The system combines IoT sensor data, mobile health reporting, and ML-based predictions to detect water quality issues and track waterborne disease outbreaks across 8 states: Assam, Meghalaya, Arunachal Pradesh, Nagaland, Manipur, Mizoram, Tripura, and Sikkim.

## Tech Stack

**Backend**
- Java 17 with Spring Boot 3.x
- Firebase Firestore (NoSQL database)
- Maven for dependency management

**Frontend**
- React 18 with TypeScript
- React Router for navigation
- Chart.js for data visualization
- Leaflet for GIS mapping

**Mobile App**
- React Native (Android)

**Integration**
- n8n for workflow automation
- Firebase Admin SDK
- REST APIs

**ML Service**
- Python with TensorFlow/PyTorch

## Key Features

- Real-time water quality monitoring (pH, Turbidity, TDS, Temperature)
- Smart alert system with disease risk assessment
- Symptom reporting and cluster detection
- Role-based access control with jurisdiction filtering
- Government-themed dashboard with GIS visualization
- Automated workflow integration via n8n webhooks
