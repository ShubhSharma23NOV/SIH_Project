PHC STAFF TEST SETUP GUIDE
==========================

STEP 1: Add Test Phone Number in Firebase Console
--------------------------------------------------
1. Go to: https://console.firebase.google.com/
2. Select your project
3. Go to: Authentication → Sign-in method
4. Click on "Phone" to expand
5. Scroll to "Phone numbers for testing"
6. Add test number:
   - Phone Number: +919999999999
   - Verification Code: 123456
7. Click "Add"

STEP 2: Create PHC Doctor Profile in Firestore
-----------------------------------------------
1. Go to: Firestore Database in Firebase Console
2. Click "Start collection"
3. Collection ID: phc_doctors
4. Document ID: (Auto-generate or use specific UID)
5. Add these fields:

   Field Name          | Type      | Value
   -------------------|-----------|---------------------------
   uid                | string    | (same as document ID)
   phoneNumber        | string    | +919999999999
   name               | string    | Dr. Test Kumar
   nameHindi          | string    | डॉ. टेस्ट कुमार
   phcId              | string    | PHC001
   phcName            | string    | Test Primary Health Center
   phcNameHindi       | string    | टेस्ट प्राथमिक स्वास्थ्य केंद्र
   district           | string    | Test District
   districtHindi      | string    | टेस्ट जिला
   block              | string    | Test Block
   blockHindi         | string    | टेस्ट ब्लॉक
   assignedAreas      | array     | ["area1", "area2", "area3"]
   role               | string    | PHC_DOCTOR
   status             | string    | active
   createdAt          | timestamp | (current timestamp)
   lastLogin          | timestamp | (current timestamp)

6. Click "Save"

STEP 3: Test Login
------------------
1. Open your app
2. Go to PHC Login screen
3. Enter phone: 9999999999 (without +91)
4. Click "Send OTP"
5. Enter OTP: 123456
6. Click "Verify & Login"
7. You should be logged in to PHC Dashboard!

TROUBLESHOOTING
---------------
If you get "Access Denied":
- Make sure the document ID in phc_doctors matches the user UID
- Check that role is set to "PHC_DOCTOR"
- Verify status is "active"

If OTP doesn't work:
- Make sure test phone number is added in Firebase Console
- Check that verification code matches (123456)
- Try using a different test number
