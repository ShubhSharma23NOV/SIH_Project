HOW IT WORKS NOW:
-----------------
- Each auth context checks AsyncStorage for 'session_type'
- ResidentAuthContext only loads if session_type is 'resident' or not set
- PHCAuthContext only loads if session_type is 'phc'
- OpsAuthContext only loads if session_type is 'ops'
- Session type is set during login in each context
- This prevents cross-loading of wrong user data
